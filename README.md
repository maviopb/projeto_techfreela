# TechFreela

O **TechFreela** é um programa desenvolvido em **Python** para auxiliar designers freelancers no cálculo rápido de orçamentos de projetos.

O sistema recebe informações sobre o cliente e o projeto e calcula automaticamente os custos envolvidos no trabalho.

## Funcionalidades

O programa solicita:

* Nome do cliente
* Nome do projeto
* Quantidade de artes
* Valor cobrado por cada arte
* Quantidade de horas previstas
* Valor cobrado por hora

Após receber os dados, o TechFreela calcula:

* Valor total das artes
* Valor das horas trabalhadas
* Valor total do projeto
